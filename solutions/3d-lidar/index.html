3D & LiDAR

One layer for every type of 3D & LiDAR labelling

From 3D bounding boxes on a single scan to track 3D objects across frames and camera-fused detections, the data labelling layer routes every point cloud data to the right 3D engine. Auto-labelling engines return results with confidence predictions above threshold are passed automatically, while low-confidence outputs go straight to a human reviewer so nothing gets shipped unverified.
